# Animorphi — портфолио

Статичный сайт-портфолио (EN/UK/RU), публикуется через GitHub Pages: https://animorphios.github.io/animorphi.os.github.io/

Контакты задаются в объекте `CONTACTS` в начале скрипта в `index.html`.

Языки: `I18N` в `index.html`, словари `en` и `uk` (русский берётся из разметки). Английский открывается по умолчанию; выбор посетителя сохраняется в `localStorage`, а `?lang=uk` открывает украинскую версию. Новый текст добавляйте сразу во все три языка, иначе кнопка покажет старый текст.

Анимации: GSAP 3.15 (ScrollTrigger, SplitText) и Lenis 1.3.26 лежат локально в `assets/vendor/`, эффекты в духе React Bits (Aurora, Shiny Text, Spotlight Card, Magnet) написаны на чистом CSS/JS. При «уменьшить движение» в системе анимации отключаются.

## Клиентские работы

- Блок «Работы для клиентов» в `index.html` (`<div class="work clients">`): SMART Business Planner, BLOGfinity, IMFINITY Immobilien, Callfinity AI. Карточки со ссылками на публичные сайты клиентов.
- **R должен подтвердить у каждого клиента, что он не против упоминания.** Если кто-то против, удалить его карточку из блока.
- В описаниях нет имён людей и контактов. Скриншоты сайтов клиентов (`assets/client-*.jpg`, снимки из `freelance/preview/case-screens/`, сжаты до 1400 px) стоят фоном карточек под тёмным градиентом. Класс `has-shot` и переменная `--shot` в `index.html` задают фон; чтобы убрать, уберите оба. Перед публикацией новых кадров проверить: нет лиц, почт, телефонов, ключей и балансов.
- Скриншоты JARVIS и AI-генерации берутся только из `freelance/preview/case-screens/`, и только кадры без личных данных.
- Блок «Популярные ролики» (`<div class="reel-grid">`): топ-4 TikTok по просмотрам, снимок от 11 октября 2026, цифры переписаны вручную (`freelance/preview/top-videos.md`). Чтобы обновить, заново снять цифры, поменять даты снимка в тексте и значения `top.v1`–`top.v4` во всех языках. Беззвучные клипы `assets/clips/clip-1…4.webm|.mp4` (10 секунд, 480×640, петля с наложением в конце) и постеры `clip-1…4.jpg` сделаны ffmpeg из выгрузки роликов R, обрезка 3:4 сверху с сохранением низа кадра, поэтому знак «Made with Flashloop App» в нижней части виден целиком (решение R). Исходники лежат в `freelance/tiktok/animorphi/`. Instagram не добавлен: там лайки, а не просмотры.
- Блок «Статистика в соцсетях»: суммы за всё время из аналитики Animorphi (снимок 12 октября 2026): просмотры и подписчики, все платформы вместе. Цифры вписаны вручную в разметку и в `soc.*` обоих языков.
- Скриншоты: JARVIS и AI-генерация обрезаны или взяты без личных данных (проверено вручную).
